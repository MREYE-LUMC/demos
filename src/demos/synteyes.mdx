This demo allows you to create realistic model geometric eyes based on the paper "Three-dimensional statistical eye models" of van Dam et al. The code can be found at [https://github.com/MREYE-LUMC](https://github.com/MREYE-LUMC).

The underlying biometric model is based on [SyntEyes by Jos Rozema](https://doi.org/10.1167/iovs.16-20877), a statistical model that generates realistic ocular biometry using a multivariate Gaussian mixture model fitted to clinical population data. The retinal component is based on the van Dam extension of this model, which adds a realistic retinal curvature model based on high-resolution MRI data of the healthy population.

This demo consists of two parts: the first part **generates complete 3D SyntEyes** with both corneal and retinal parameters, while the second part allows you to **generate realistic retinal radii** for a specific axial length.
